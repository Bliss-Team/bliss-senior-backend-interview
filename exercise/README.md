# AI Twin message exercise

This is a credential-free TypeScript model of one Bliss backend path. It is intentionally incomplete and unsafe in several production-relevant ways.

From this directory:

```bash
npx npm@10.9.2 install
npm test
```

If the parent Bliss repository already has dependencies installed, this also works from the repository root:

```bash
npx tsx --test interview/senior-backend-ai-twin/exercise/tests/*.test.ts
```

Some tests fail initially by design. You are not expected to fix everything. See [`../CANDIDATE_README.md`](../CANDIDATE_README.md) for the task and timing.
