# Bliss Senior Backend Engineer interview

Start with [CANDIDATE_README.md](./CANDIDATE_README.md). It contains the full interview format, architecture context, coding task, incident packet, and architecture discussion.

This is **not a LeetCode-style interview**, and you are not expected to already know the Bliss architecture. You are evaluated on debugging, backend reasoning, production judgment, security, reliability, prioritization, communication, and how effectively you use normal development tools.

AI tools are fully allowed. You may use ChatGPT, Claude, Codex, Copilot, Google, Stack Overflow, official documentation, or any other normal development tool. You should explain your reasoning while working and verify any generated advice or code. You are not expected to fix every issue during the available time.

All system descriptions, names, metrics, timestamps, incident evidence, and records in this repository are sanitized or synthetic. This repository contains no production credentials or real user, therapist, conversation, or payment data.
